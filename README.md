# Movie Recommendation System

## Project Overview
This project is a content-based Movie Recommendation System that suggests similar movies based on movie genres and textual features.
The system analyzes movie characteristics and recommends movies that share similar attributes using text vectorization and cosine similarity.

## Dataset
Custom Movie Dataset

Features:
* Movie Title
* Genre Information

## Technologies Used
* Python
* Pandas
* Scikit-Learn
* CountVectorizer
* Cosine Similarity

## Recommendation Workflow
1. Load movie dataset
2. Convert text features into vectors
3. Calculate similarity matrix
4. Compare movie similarity scores
5. Recommend most similar movies

## Machine Learning Concepts Used
* Natural Language Processing (NLP)
* Text Vectorization
* CountVectorizer
* Cosine Similarity
* Recommendation Systems

## Features
* Content-based recommendations
* Similarity score calculation
* User movie search
* Top movie recommendations
* Error handling for unavailable movies

## Example
Input:
Batman

Output:
* Superman
* Spider Man
* Avengers
* Iron Man
